## Reproduction and remaining gates

Use an installed Claude Code and Git Bash on Windows, build this source, then
request a fresh evidence destination:

```powershell
cargo build --locked -p agentfw --bin agentfw
python -I scripts/windows-claude-mcp-acceptance.py --run --evidence target/claude-mcp-new.json
```

Without `--run`, the command emits a manifest and starts no processes. See the
[operator contract](../../operations/MCP_STDIO_ADMISSION.md) for registry,
daemon and supported payload requirements.

This is sequential, reviewed string-argument/text-result stdio admission to
the MCP **host**, not attestation of its eventual model context. Unknown
metadata, batches, concurrency, server requests, structured/media/resource
results and progress notifications are rejected. Server stderr and arbitrary
process I/O are outside admission; the chosen server executable remains
operator-trusted. Legacy MCP manifest collection and observation-only
PostToolUse keep their existing contracts.

General MCP authority, human result approval, broader registry coverage,
shipped-policy effectiveness, held-out attack outcomes, live defended task
utility, managed deployment and real-IdP interoperability remain open.
Real-model work requires an operator-selected provider, access and spend budget.
